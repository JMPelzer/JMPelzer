## 🧭 Design Philosophy (short)
I design for **people first**. Accessibility and usability reinforce each other: when we remove friction, everyone benefits.

- Built-in accessibility (not a retrofit)  
- Content first (plain language, meaningful headings)  
- Performance as part of a11y (fast = more inclusive)  
- Semantic HTML, correct/limited ARIA  
- Keyboard support, visible focus, no color-only cues

<details>
<summary>View my full checklist</summary>

- Contrast ≥ **4.5:1** (text) / ≥ 3:1 (large text/icons)  
- Logical tab order, skip links, no traps  
- Descriptive alternatives (`alt`, captions, transcripts)  
- Landmarks: `<header>`, `<nav>`, `<main>`, `<footer>`  
- Accessible forms: labels, helpful errors, `aria-describedby`  
- Respects `prefers-reduced-motion` and color scheme  
- Zoom to 200%+ without loss of content  
- Minimal, optional animation; no auto-play media  
- Performance budgets; test with WAVE/Lighthouse
</details>
