## 🧭 Design Philosophy
- Accessibility isn’t an add-on — it’s part of the build process.  
- WCAG color contrast ratio > 4.5:1  
- Every image includes descriptive **alt** text.  
- Code examples use **semantic HTML** and **ARIA** where appropriate.  
- Minimal animations. Clean hierarchy. Clear CTAs.
